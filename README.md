# Technical Task 1: Signup Form & Dashboard

## How to Run
1. Open `index.html` in any web browser.

## Features Implemented
* **Validation:** Requires a username, standard email format, and a 6+ character password.
* **Storage:** Uses browser `localStorage` to save data and simulate a database.
* **Hashing:** Simulates password hashing using `btoa()` encoding.
* **Brownie Points - Delete:** Users can be deleted from the dashboard table.
* **Brownie Points - Dark Mode:** Implemented a theme toggle that persists across refreshes using `localStorage`.
